# Organization-Management-Service

This is a coding challenge project for **Swiss Re**. The application allows uploading and analyzing CSV files via a web interface.

---

## Prerequisites

- **Java JDK 17+** (Ensure your system is running at least Java 17)  
  ```bash
  java -version

git clone [<repository-url>](https://github.com/Sandi-09/Organization-Management-Service)]
cd Organization-Management-Service

Run these commands : 
mvn clean install
mvn spring-boot:run


  
Steps to Run the project:
1.Once the project starts running it commes up on port 8080 with the context as /organisationManagement
2.Verify the same using the '/hello' url
